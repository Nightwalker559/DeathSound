# DeathSound — Sound & Emote

> Spielt einen eigenen Sound und zeigt ein eigenes Emote-Bild wenn dein Charakter stirbt — und optional ein Emote neben dem Gruppenfenster, wenn ein Gruppenmitglied stirbt.

---

## 🇩🇪 Deutsch

### Installation
1. Den Ordner `DeathSound` in dein WoW-AddOns-Verzeichnis kopieren:
   `World of Warcraft\_retail_\Interface\AddOns\DeathSound\`
2. WoW starten — fertig.

---

### Ordnerstruktur

```
DeathSound\
├─ DeathSound.toc
├─ UpdateLists.bat.txt     zu UpdateLists.bat umbenennen (siehe unten)
├─ Core\                   DeathSound.lua (Sound, Optionen), DeathOverlay.lua (Overlay, Gruppen-Emote)
├─ Data\                   SoundList.lua, ImageList.lua (werden von UpdateLists.bat erzeugt)
├─ Locales\                enUS (Fallback), deDE
├─ UI\                     ElvUI_Skin.lua
└─ Media\
   ├─ Sounds\              .ogg / .mp3
   └─ Images\              .png / .tga
```

---

### Eigene Sounds hinzufügen
1. `.ogg` oder `.mp3` Dateien in den Ordner legen:
   `Interface\AddOns\DeathSound\Media\Sounds\`
2. `UpdateLists.bat.txt` im Addon-Ordner zu `UpdateLists.bat` umbenennen und ausführen
   → scannt den Sounds-Ordner und schreibt `Data\SoundList.lua` automatisch
3. `/reload` genügt — kein kompletter Neustart nötig.
4. Im Spiel den Sound über das Optionen-Panel auswählen.

---

### Eigene Overlay-Bilder hinzufügen
1. `.png` oder `.tga` Dateien in den Ordner legen:
   `Interface\AddOns\DeathSound\Media\Images\`
   - **Empfohlenes Format:** `.png` — kleinere Dateien, Alpha-Kanal, universell kompatibel
   - **Legacy-Format:** `.tga` — wird weiterhin unterstützt
   - Maximale Größe im Spiel: `128×128` px
   - Beide Formate unterstützen Transparenz via Alpha-Kanal
2. `UpdateLists.bat` ausführen (liegt im Addon-Ordner)
   → scannt den Images-Ordner und schreibt `Data\ImageList.lua` automatisch
3. `/reload` genügt
4. Im Optionen-Panel, Tab **Emote**:
   - **Bild-Overlay beim Tod anzeigen** aktivieren
   - Bild aus dem Dropdown auswählen
   - Optional **Zufällig** aktivieren → zeigt bei jedem Tod ein anderes Bild
   - Optional **An 'Geist freilassen'-Popup ankern** → Bild erscheint links neben dem Todes-Dialog, Größe automatisch
   - **Entsperren (Bearbeiten)** klicken → Overlay per Drag verschieben
   - Größe im Eingabefeld eintragen (32–128 px, quadratisch)
   - **Position sperren** wenn fertig

---

### Gruppen-Emote
Im Tab **Gruppe** zeigt DeathSound ein Emote neben dem Gruppenfenster eines toten Gruppenmitglieds (Standard-UI inklusive Raid-Style-Party und ElvUI).
- **Emote bei Tod eines Gruppenmitglieds anzeigen** aktivieren
- Bild wählen, optional **Zufällig** — das Bild wird pro Tod und Mitglied einmal gewählt
- **Position:** links, rechts, oben oder unten am Gruppenfenster, dazu ein Abstand (0–64 px)
- **Testen** zeigt das Emote 6 Sekunden an allen sichtbaren Gruppenfenstern
- In Raidgruppen und Raid-Instanzen wird es nie angezeigt

---

### Optionen
Über **ESC → Optionen → AddOns → DeathSound** oder per Slash-Command.

| Befehl | Funktion |
|---|---|
| `/deathsound` | Optionen-Panel öffnen |
| `/deathsound test` | Aktuellen Sound testen |
| `/deathsound on` | Addon aktivieren |
| `/deathsound off` | Addon deaktivieren |
| `/deathsound hilfe` | (jeder andere Text) Befehlsliste anzeigen |
| `/ds` | Kurzform für alle Befehle |

### Unterstützte Formate

| Typ | Format | Anmerkung |
|---|---|---|
| Sound | `.ogg` | Empfohlen |
| Sound | `.mp3` | Unterstützt |
| Overlay | `.png` | Empfohlen — klein, Alpha-Kanal, universell |

---

### Kompatibilität
- World of Warcraft: Midnight, Patch 12.1 & 12.1.5 (Interface 120100, 120105)
- ElvUI: Skin wird automatisch angewendet wenn ElvUI aktiv ist

---

### Hinweise
- Sound- und Bilddateien müssen vor dem `UpdateLists.bat`-Lauf im Ordner liegen; danach reicht `/reload`
- `UpdateLists.bat` muss direkt im `DeathSound\` Ordner liegen
- Wer Listen mit einer älteren `UpdateLists.bat` erzeugt hat, führt die neue einmal aus (die Listen liegen jetzt in `Data\`)
- Wenn ein Sound nicht abspielt, wird der volle Dateipfad im Chat ausgegeben
- Das Overlay erscheint automatisch beim Tod und verschwindet bei Wiederbelebung
- Wenn DeathSound deaktiviert ist, erscheinen weder Sound noch Emote-Bild

## 🇬🇧 English

### Installation
1. Copy the `DeathSound` folder into your WoW AddOns directory:
   `World of Warcraft\_retail_\Interface\AddOns\DeathSound\`
2. Start WoW — done.

---

### Folder Structure

```
DeathSound\
├─ DeathSound.toc
├─ UpdateLists.bat.txt     rename to UpdateLists.bat (see below)
├─ Core\                   DeathSound.lua (sound, options), DeathOverlay.lua (overlay, group emote)
├─ Data\                   SoundList.lua, ImageList.lua (generated by UpdateLists.bat)
├─ Locales\                enUS (fallback), deDE
├─ UI\                     ElvUI_Skin.lua
└─ Media\
   ├─ Sounds\              .ogg / .mp3
   └─ Images\              .png / .tga
```

---

### Adding Your Own Sounds
1. Place `.ogg` or `.mp3` files into:
   `Interface\AddOns\DeathSound\Media\Sounds\`
2. Rename `UpdateLists.bat.txt` in the addon folder to `UpdateLists.bat` and run it
   → scans the Sounds folder and writes `Data\SoundList.lua` automatically
3. `/reload` is enough — no full restart needed.
4. Open the options panel, go to the **Sound** tab and select your sound.

---

### Adding Your Own Emote Images
1. Place `.png` or `.tga` files into:
   `Interface\AddOns\DeathSound\Media\Images\`
   - **Recommended format:** `.png` — smaller files, alpha channel, works everywhere
   - **Legacy format:** `.tga` — still supported
   - Maximum size in-game: `128×128` px
   - Both formats support transparency via alpha channel
2. Run `UpdateLists.bat` (located in the addon folder)
   → scans the Images folder and writes `Data\ImageList.lua` automatically
3. `/reload` is enough
4. Open the options panel, go to the **Emote** tab:
   - Enable **Show image overlay on death**
   - Select an image from the dropdown
   - Optionally enable **Random** to cycle through images randomly on each death
   - Optionally enable **Anchor to Release Spirit popup** — the image will appear to the left of the death dialog, sized automatically
   - Click **Unlock (Edit Mode)** to drag the overlay to your preferred position
   - Enter a size in the input field (32–128 px, square)
   - Click **Lock Position** when done

---

### Group Emote
On the **Group** tab DeathSound shows an emote next to the unit frame of a dead party member (default UI including raid-style party frames, and ElvUI).
- Enable **Show emote on party member death**
- Pick an image, optionally **Random** — the image is chosen once per death and member
- **Anchor position:** left, right, top or bottom of the party frame, plus an offset (0–64 px)
- **Test** shows the emote on all visible party frames for 6 seconds
- It is never shown in raid groups or raid instances

---

---

### Compatibility

---

### Notes
- Sound and image files must be in place before running `UpdateLists.bat`; a `/reload` afterward is enough
- `UpdateLists.bat` must be located directly in the `DeathSound\` folder
- If you generated your lists with an older `UpdateLists.bat`, run the new one once (the lists now live in `Data\`)
- If a sound fails to play, the full file path is printed to chat
- The overlay appears automatically on death and hides on resurrection
- If DeathSound is disabled, neither the sound nor the emote image will appear
